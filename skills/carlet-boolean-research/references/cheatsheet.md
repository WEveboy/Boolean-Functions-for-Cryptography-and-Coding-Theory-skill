# 决策规则速查 — Boolean Functions for Cryptography and Coding Theory

| 能力 | 一句话规则 |
|---|---|
| 表示、位序与ANF | 把函数真值表转成唯一平方自由ANF，明确等价关系及不变量。 |
| Walsh谱与非线性度 | 用未归一化Walsh谱计算到全部仿射函数的距离。 |
| 全部分量、DDT与S盒指标 | 检查每个非零输出掩码，差分均匀度不包含零输入差分。 |
| Reed–Muller距离与码参数 | 把次数约束转为码空间，区分最小距离与覆盖半径。 |
| 二次极化秩与谱支撑 | 次数至多2才可用极化双线性型的秩预测谱幅度和支撑。 |
| 构造并核验bent与plateaued | 在明确偶数维和置换前提下构造Maiorana–McFarland函数。 |
| 相关免疫与韧性阶数 | 低重量非零频点为零刻画相关免疫，韧性还要求零频为零。 |
| 自相关、SAC与传播准则 | 用导数平衡核验传播准则，并区分重量1方向与全部方向。 |
| 代数免疫与零化子证书 | 在f或f+1的支撑上解齐次线性系统，求非零低次零化子。 |
| 对称族与受限输入核查 | 逐重量层和旋转轨道核查性质，完整域与受限域参数分开报告。 |
| 有限域模型与APN幂函数实验 | 先固定不可约模多项式再生成幂函数，有限实验与族定理分开。 |
| 攻击模型与实现假设审查 | 把攻击者可观察量和实现条件写清，再选择相关函数指标。 |
| 历史开放问题与证据分级 | 把出版时开放问题转成可检验的小任务，并把当前状态留给文献核查。 |
| BCT与boomerang均匀度 | 只在置换上计算逆函数BCT，最大值排除两个零差分轴。 |
| 绝对迹与多项式基对偶基 | 固定不可约模多项式和多项式基，用迹配对恢复坐标内积。 |
| 给定EA与CCZ等价证书 | 验证给定可逆仿射变换的逐点等式，不把失败证书当成不等价证明。 |
| 预算内精确高阶非线性度 | 将高阶非线性度落实到RM码的有限精确距离，先核枚举规模。 |
| 函数生成码、秩门与重量分布 | 先计算实际生成矩阵秩，再枚举不同码字；退化参数不套满秩距离公式。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
