# Boolean Functions for Cryptography and Coding Theory

Claude Carlet，Cambridge University Press，2021。输入为用户指定的577页PDF。正文印刷页p对应PDF第p+15页（1起算）。

主旨：通过表示、谱、导数和代数结构，把密码攻击提出的函数约束转为可证明的构造及编码性质。

## 结构与论证

1. 第1–2章建立密码、码、函数表示和等价关系；真值表、ANF、迹表达各自暴露不同结构。
2. 第3–4章从攻击模型形成指标，并把非线性度翻译为Reed–Muller距离。
3. 第5–6章利用仿射、二次及谱可控结构构造bent和plateaued函数。
4. 第7–10章讨论相关免疫、传播、代数免疫与特殊函数类，揭示指标之间的约束。
5. 第11章以低差分均匀度、APN及AB构造为向量函数设计中心。
6. 第12–14章拓展到物理攻击、FHE、局部PRG、Gowers范数，列开放问题并补充有限域。

论证主轴是表示恒等式→指标判据→结构性构造→必要条件与例外；不是单一指标决定系统安全。

## 术语与批判

Walsh采用未归一化符号和；分量为所有非零输出掩码对应的标量函数；NL为到仿射函数的最小距离；AI通过f或f+1的非零零化子定义。bent要求偶数输入维，不能同时平衡；APN不是置换的同义词。

出版时的攻击成本、安全门槛、已知函数族与第13章问题均为历史材料。没有联网逐题复核前不标为2026年仍开放。数学指标提供局部约束，不证明整套密码或物理实现安全。正文中的高阶分类与新族证明不能由小维穷举替代。
