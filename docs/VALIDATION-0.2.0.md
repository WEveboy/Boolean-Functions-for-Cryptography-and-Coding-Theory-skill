# 0.2.0 验证记录

在0.1.0已发布基线之上增加5卡、7个JSON操作和核心见证输出。保留18个稳定能力ID；旧卡revision递增，新增卡从1起。0.1版26项双变体评测是历史记录，本版没有伪称重新完成该对照实验。

## 原书依据与独立实现

BCT见p.141式(3.42)，不是此前粗定位p.140；EA/CCZ为pp.28–29；高阶距离见p.157；函数码p.160明确无仿射分量前提；绝对迹与双基见p.489。详见books/carlet-2021/references/v0.2-source-audit.md，含原页目视与逐项短引。Gray码、批处理和JSON结构是本项目D实现，不归因为原书新定理。

审阅确认：函数码必须按实际秩统计不同码字；退化时向量NL=0不推出码最小距离0。include_constant=false时也不能套含常数代码的d=NL公式。BCT定义要求置换；给定证书失败只否定该证书。

独立审阅发现负数mod可绕过旧bit_length检查，引起负数位运算循环；已补mod>0和两项拒绝回归。审计保留发现时记录，最新代码以修复后的实际测试为准。

## 有限算法与CLI实测

12组unittest全部通过。保留全部256个三变量函数的谱/距离/AI对拍、384个MM构造；新增BCT与二元配对式独立计数、GF(2)迹线性与对偶基坐标重建、给定证书正反例和奇异矩阵拒绝、全部三变量函数的精确NL2及最近ANF见证、随机函数码全参数去重对照、批处理错误隔离与禁止嵌套。

新增全8位GF(256)逆函数（mod=0x11B）的全分量谱/DDT：delta=4、NL=112、置换成立；含常数函数码秩17、枚举131072个不同码字、最小距离112；枚举重量分布另与全部分量Walsh到重量恒等式逐项一致。该例支持将向量和证书预算扩大到n,m<=8、n+m<=16；函数码维数<=17。精确高阶距离仍限制枚举维数<=16，未静默放宽。

独立来源审阅另实跑：全部24个2位置换的BCT、全部256个(2,2)映射的重量分布、全部256个三变量函数的NL2及GF(8)对偶基，均一致。不是全8位空间穷举或无限族证明。
